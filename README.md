# 持股追蹤

台股＋美股的持股追蹤網頁。電腦和手機都能用，資料會自動同步。

**這一階段有：**
- 持有／觀察列表
- 即時報價（台股約 5 秒更新，盤中自動刷新）
- 交易與股利紀錄，手續費和證交稅自動帶入
- 平均成本、未實現損益、已實現損益、股利、預期損益
- 深色／淺色切換
- 日／週／月 K 線：成交量、MA5／20／60、成本線、目標價線、買賣點
- ChatGPT 重點時間軸：一鍵複製整理指令，貼回來依代號自動分到各檔標的，並分類成主題 → 子主題 → 重點，標在 K 線上
- 列表拖拉排序，拖到「持有／觀察」分頁就能換區
- 固定的分類規範（12 個主題，含 AI research），可以直接匯入照規範整理好的 JSON 檔
- 每檔標的有「我的策略」，和公司情報分開
- 資料整理：全螢幕表格，可以跨標的篩選、批次刪除與編輯、找疑似重複、合併子主題；刪除先放回收桶，每個動作都能復原
- AI 推論可以連回依據的資料，兩邊互相跳轉；被推翻的判斷標「已過時」保留
- 多空指標：子主題、主題、標的三層都有，外部資訊和 AI 分開算
- 新聞收件匣：Apps Script 每小時收集新聞和公司公告，存在你的 Google 雲端硬碟；你同意後才變成重點，也可以整批交給 ChatGPT 整理
- 資料存在瀏覽器的資料庫，資料量大也存得下
- 公司資料與財報：基本資料、估值、股利、季度和年度財報、月營收，可以展開成全螢幕；財報類的重點會自動和官方數字對照
- Memory 銀河系：以標的為星系核心，主題 → 子主題 → 重點沿著旋臂往外排；可以自由旋轉、平移、縮放，點選時路徑會發光
- 四個區塊可以拖拉分隔線調整大小，內容跟著重新排版

> **升級：** 把新的 `index.html` 上傳到 GitHub、覆蓋舊的就好，資料不受影響。
> **這一版的 Apps Script 也更新了**（多了新聞收集、公司資料與財報）。請照下面「步驟五」更新一次；不更新也能照常用其他功能。

## 整體怎麼運作

```
你的電腦／手機（瀏覽器）
   ├─ 網頁本體 ← GitHub Pages（公開，只有程式，沒有你的資料）
   ├─ 即時報價 ← Google Apps Script ← 證交所／Yahoo Finance
   └─ 持股資料 ⇄ 你的 GitHub 私人 repo（data.json）
```

- 網頁程式碼是公開的，但裡面沒有任何個人資料。
- 你的持股和交易只存在兩個地方：你的瀏覽器，和你自己的**私人** repo。
- 每次儲存都會在私人 repo 留下一個版本，萬一改錯可以從歷史紀錄找回來。

## 步驟一：部署報價中繼（Google 帳號，約 5 分鐘）

1. 打開 <https://script.google.com>，按「新專案」。
2. 刪掉編輯器裡預設的內容，把 `apps-script/Code.gs` 整份貼上，按 Ctrl+S（Mac 是 ⌘+S）存檔。左上角的專案名稱可以改成「持股追蹤報價」。
3. **授權（只需要一次）：**
   1. 上方工具列的函式選單選 `testSetup`，按「執行」。
   2. 跳出「需要授權」時按「審查權限」，選你的 Google 帳號。
   3. 看到「Google 尚未驗證這個應用程式」是正常的，因為這是你自己寫的程式。按「進階」，再按「前往…（不安全）」，最後按「允許」。
   4. 下方「執行紀錄」出現台積電、美股和匯率的資料，就代表成功了。
4. **部署：**
   1. 右上角按「部署」，選「新增部署作業」。
   2. 按左邊的齒輪，類型選「網頁應用程式」。
   3. 「執行身分」選**我**，「誰可以存取」選**所有人**。
   4. 按「部署」，把「網頁應用程式網址」複製下來（結尾是 `/exec`）。
5. **確認：** 在瀏覽器打開「剛剛的網址 + `?tw=2330&us=AAPL&fx=1`」，看到一串 JSON 資料就成功了。

> 「所有人」的意思是拿到這個網址的人可以用它查股價。這個中繼只會轉傳公開的股價，不會碰到你的持股資料。如果還是想上鎖，可以在 `Code.gs` 最上面的 `ACCESS_KEY` 填一段密語，網頁設定的「存取密語」也填一樣的。

> **之後如果改了 Code.gs：** 到「部署 → 管理部署作業」，按鉛筆圖示，版本選「新版本」，再按「部署」。網址不會變。

## 步驟二：建立兩個 GitHub repo

### A. 放網頁的公開 repo

1. 登入 GitHub，右上角按「+」，選「New repository」。
2. Repository name 填 `stock-tracker`，選 **Public**，按「Create repository」。
3. 在新 repo 的頁面按「uploading an existing file」，把 `index.html` 拖進去，按「Commit changes」。
   - 只放 `index.html` 就好。
   - 如果你在 Code.gs 設了 ACCESS_KEY，**不要**把 Code.gs 傳上來。
4. 到 repo 的 **Settings → Pages**：
   - Source 選「Deploy from a branch」。
   - Branch 選「main」和「/ (root)」，按「Save」。
5. 等 1～2 分鐘，重新整理頁面，上方會出現網址：`https://你的帳號.github.io/stock-tracker/`。

### B. 放資料的私人 repo

1. 再建一個新 repo，名稱填 `stock-tracker-data`，這次選 **Private**，按「Create repository」。
2. 裡面空的就好，網頁第一次同步時會自動建立 `data.json`。

## 步驟三：建立 GitHub token（同步用）

這個 token 只能讀寫 `stock-tracker-data` 這一個 repo，碰不到你其他的東西。

1. GitHub 右上角頭像 → **Settings** → 左側最下面 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**。
2. 設定：
   - **Token name**：`持股追蹤`
   - **Expiration**：選長一點。到期後重新產生一個，填回網頁就好。
   - **Repository access**：選「Only select repositories」，然後只勾 `stock-tracker-data`。
   - **Permissions**：找到 **Contents**，設成 **Read and write**。Metadata 會自動變成唯讀，這是正常的。
3. 按「Generate token」，把 `github_pat_…` 開頭的那串複製下來。**這串只會顯示一次**，先貼在安全的地方。

## 步驟四：開始使用

### 電腦

1. 打開 `https://你的帳號.github.io/stock-tracker/`。
2. 右上角的設定圖示（滑桿形狀）：
   - **報價來源**：貼上步驟一的 `/exec` 網址。
   - **GitHub token**：貼上步驟三的 token。
   - **資料 repo**：如果名稱是 `stock-tracker-data`，留空即可。
   - **台股手續費折扣**：照你的券商填，例如 2.8 折填 `0.28`，6 折填 `0.6`。
3. 按「儲存」。右上角的雲朵圖示不是紅色或橘色，就代表同步好了。
4. 按「新增標的」開始建立持股：
   - 選「已持有」，接著會直接跳出買進交易的視窗。
   - 選「觀察中」，就只追蹤價格和目標價。

### 手機

1. 用手機打開同一個網址。
2. 到設定，**只要貼 GitHub token** 就好。報價來源和手續費設定會跟著資料一起同步過來。
3. 加到主畫面，用起來就像一個 App：
   - **iPhone（Safari）**：按分享按鈕，選「加入主畫面」。
   - **Android（Chrome）**：按右上角 ⋮，選「加到主畫面」。

## 步驟五：新聞、公司資料與財報（選用，約 3 分鐘）

新聞和公司公告每小時收集一次，公司資料與財報每 12 小時收集一次，都由你的 Apps Script 去抓，存在**你自己的 Google 雲端硬碟**，不會經過別人的伺服器。

1. 打開步驟一的 Apps Script 專案，把新的 `apps-script/Code.gs` **整份**貼上取代，存檔。
2. 上方函式選單選 `setupNews`，按「執行」。這次會多要求**雲端硬碟**的權限，照步驟一的方式按「允許」。它會：
   - 在雲端硬碟建立資料夾 `stock-tracker-news`。
   - 設定每小時自動收集一次（財報也在這時順便檢查，每 12 小時更新）。
3. 部署新版本：「部署 → 管理部署作業」，按鉛筆圖示，版本選「新版本」，按「部署」。網址不會變。
4. 回到網頁，打開「設定」，「新聞收集」那一區會顯示是否已經自動收集、追蹤幾檔、各來源的狀況。按「立即收集一次」可以馬上收。

**收集哪些來源**（都是免費、不需要帳號的）：
| 市場 | 公司公告 | 新聞 |
|---|---|---|
| 台股 | 證交所、櫃買中心的「每日重大訊息」 | Google 新聞（依公司名稱搜尋）、Yahoo 奇摩股市 |
| 美股 | SEC 公告（選填，見下方） | Google 新聞、Yahoo Finance |

- 網頁會自動把你的追蹤清單傳給 Apps Script，新增或刪除標的不用另外設定。
- 某個來源暫時抓不到（例如對方改版），設定裡會顯示錯誤，其他來源照常收集。
- **美股 SEC 公告**：SEC 規定每次請求都要附上聯絡資訊。想收的話，在 `Code.gs` 最上面附近的 `SEC_CONTACT` 填「你的名字 你的email」，再部署新版本。
- 新聞檔案依「市場_代號_月份」分開存，例如 `TW_6488_2026-11.json`，一直保留。只存標題、來源、時間、連結和一小段摘要，不存新聞全文。
- 財報檔案每檔一個，例如 `FIN_TW_6488.json`。官方只提供最新一期，所以每期都會存下來，月營收和季度的歷史會越來越完整；更早的由 Yahoo 補。
- 已經做過步驟五的，這次只要重新貼上 Code.gs、部署新版本，不用再執行 setupNews。

## 使用說明

### 持有和觀察
- 持股大於 0 的標的會出現在「持有」。
- 沒有交易紀錄，或已經全部賣光的，會出現在「觀察」。賣光的標的仍然保留已實現損益。

### 排序與換區
- 每一列左邊的 ⠿ 是拖拉把手。電腦直接拖；手機按住把手拖，才不會和捲動畫面打架。
- 順序會跟著資料同步到其他裝置。
- 預設台股、美股分開列，只能在同一組裡排序。到設定取消「台股、美股分開列」，就能混在一起自由排。
- **換區**：把標的拖到上方的「持有」或「觀察」分頁標籤上放開。
  - **觀察 → 持有**：跳出買進視窗，記好交易就移過去。
  - **持有 → 觀察**，可以選兩種：
    - **全部賣出**：跳出賣出視窗，股數已經填好全部持股。
    - **只移到觀察，不賣**：持股保留，但市值和損益**不列入**頂部總覽。列表會標示「有持股・不計入總覽」，拖回「持有」就會恢復。

### 交易
- 手續費和證交稅會依設定自動算：
  - 手續費無條件捨去，並套用最低手續費（整股 20 元、零股 1 元，可以改）。
  - 證交稅：股票 0.3%；代號 00 開頭的 ETF 用 0.1%。
- 自動算的金額可以直接改成對帳單上的實際金額，改過的欄位就不會再被自動覆蓋。

### 股利
- **現金股利**：填股利總額和扣除額。台股的扣除額包括二代健保補充保費、匯費；美股是預扣稅，一般是 30%。
- **股票股利（配股）**：填配發股數。持股會增加，總成本不變，所以平均成本會下降。

### 損益怎麼算
| 項目 | 算法 |
|---|---|
| 平均成本 | 移動平均，含買進手續費 |
| 已實現損益 | 賣出所得（扣手續費和稅）− 賣出股數 × 當時平均成本 |
| 未實現損益 | 市值 − 預估賣出手續費 − 預估證交稅 − 持有成本 |
| 預期損益 | 用目標價算的未實現損益（一樣扣除預估的費用和稅） |
| 總報酬 | 已實現 + 未實現 + 股利實收 |

頂部的總覽用台幣合計，美股用即時匯率換算。

### 顏色
- 台股：紅漲綠跌。
- 美股：綠漲紅跌。
- 頂部的台幣合計照台股習慣。
- 每個數字都有 ▲▼ 和正負號，不用只看顏色。

### 更新頻率
- 台股 9:00～13:30、美股 9:30～16:00（紐約時間）的平日，會照設定的秒數自動更新，預設 10 秒。
- 收盤後就停止自動更新，打開網頁或切回網頁時會抓一次最新價格。
- 國定假日沒有特別判斷，會照常嘗試更新，但價格不會變。

### K 線
- 上方可以切換日 K、週 K、月 K。日 K 盤中會用即時報價更新今天那一根。
- **電腦**：滾輪縮放、按住拖曳平移，雙擊或按右邊的 ⇥ 回到最新。
- **手機**：左右滑動平移、雙指縮放，上下滑動照常捲動頁面。
- 點一根 K 棒，下方會列出那天（週 K、月 K 是那段期間）的重點，右下的時間軸也會標亮對應的重點。
- 標記代表的意思：
  - 「買」：在 K 棒下方。
  - 「賣」：在 K 棒上方。
  - 實心圓點：重點。顏色代表看法，偏多、偏空照當地漲跌色，中性是藍色；數字是同一天有幾條。
  - 空心圓圈：只知道月份或季度的重點，畫在那段期間的開頭。
  - 日期不明的重點（例如一般觀點、AI 推論）不會畫在 K 線上，只出現在時間軸。
- 虛線是**成本線**（持有才有）和**目標價線**。超出畫面時，會在邊緣顯示「目標 1,300 ↑」。
- 「買賣點」「重點」兩個按鈕可以開關標記。
- 已過時的重點、只知道年份的重點也不畫。
- 報價區會顯示：
  - **距高點**：最近 250 個交易日最高價到現價的跌幅。點一下可以切換 20／60／120／250 日，畫面會標出用的是哪個區間。
  - **預估本益比**：用「估值 › 獲利預估」裡的 EPS（同一年有好幾筆就取中位數）和即時股價計算，股價一動就跟著更新。已過時的預估不算。

### ChatGPT 重點
分類照 `data/stock_tracker_classification_rules_v2.3.md` 這份規範，整理指令會把規範的重點一起交給 ChatGPT。

**固定的 12 個主題**

| 分組 | 主題 |
|---|---|
| 公司基本面 | 產品業務、營收財報、營運狀況、管理層、新聞事件 |
| 外部環境 | 產業與競爭、資金籌碼、市場數據 |
| 市場研究 | 估值、分析師看法、風險、AI research |

- **AI research**：ChatGPT 自己**新提出**的推論、判斷、估值情境放這裡，和外部來源的資訊分開。ChatGPT 只是摘要或翻譯新聞、財報、分析師說法的，依內容放一般主題。
- **依據**：每條 AI 推論會附上同一次整理裡支持它的重點（`evidence_ids`）。沒有依據的會標「待補證據」，可以在「資料整理」手動連結。
- **市場數據**：只放跌停、爆量、創新高或新低這類特殊事件，原因不明也可以記。一般的收盤價、盤中價、試算跌幅都不存，K 線上本來就有。

**流程**
1. 在 ChatGPT 討論股票。一次聊好幾檔也可以。
2. 討論完，按列表上方的「ChatGPT 重點」或時間軸上方的「複製整理指令」，把指令貼到**同一個** ChatGPT 對話。指令會：
   - 附上你清單裡所有標的的代號，要求每條重點標明是哪一檔。
   - 附上固定的主題、子主題和判斷規則。
   - 要求 ChatGPT 不能補充對話裡沒提到的事、不能編造依據或連結。
3. 把 ChatGPT 的回覆整段複製回來，按「貼上匯入」。也可以按「選擇 JSON 檔案」，直接匯入照規範整理好的檔案（例如 `data/` 裡的那份）。
4. 網頁會**依每條重點的代號自動分到對應的標的**：
   - 2330、2330.TW、TPE:2330、全形的２３３０都認得。
   - 沒寫代號的，用公司名稱比對。
   - 代號和名稱都沒寫的，歸到目前選的那一檔。
   - 不在你清單裡的標的（包括 JSON 裡 `watchlist` 列的），可以選「新增到觀察」、「歸到某一檔」或「略過」。ETF 會自動標記，證交稅用 ETF 稅率。
   - 台積電 ADR（TSM）和 2330 是不同的標的，不會因為名稱相近就自動合併。
5. 確認畫面依標的分組，並標出：
   - **新主題**、**新子主題**：可以選擇併入已有的分類。
   - **可能重複**：標題相同，而且 id 相同、同一天，或兩邊日期都不明，預設不勾選。只有 id 相同不算，因為每次對話 ChatGPT 都會從 001 開始編號。
   - **之前刪除過**：你刪過的雜訊，再匯入時預設不勾選，不會又跑回來。
   - 檔案裡如果有**持倉、組合快照、攤平試算**，會提示這些**不會匯入**。持倉請到交易紀錄手動新增。
6. 按「匯入」。**匯入是新增，不會覆蓋已有的重點。** 重點會出現在各檔的時間軸和 K 線上；策略會放進「我的策略」。
7. 匯入完的提示上有「整理這批」，可以直接打開「資料整理」，只看剛匯入的這批，把雜訊刪掉。

**時間軸上看得到的資訊**
- **類型標籤**：事實、預測、觀點、假設、自述、預定。ChatGPT 的推論會多一個「AI」標籤。
- **日期**：只知道月份的顯示「（月）」，日期不明的顯示「整理」，代表那是整理的日期，不是事件日期。
- **分析師名稱、財報期間、目標期間、相關標的**：相關標的可以點，直接跳到那一檔。
- **狀態標籤**：「待補證據」「待檢視」「已過時」「已查證」，異常行情另有原因標籤（已確認、有報導、推測、不明）。
- **展開後**：顯示來源、是否重新查證、原始連結，以及**依據**或**相關 AI 推論**；點一下就跳到那一條。
- **多空指標**：最上方是整檔的多空；選了主題就變成那個主題的多空，分析師看法還會依分析師分開列。期間可以選全部、近 90 天、近 30 天。
- **篩選**：
  - 上方可以依主題篩選，也可以依類型或分析師篩選，例如「郭哲榮的所有預測」。
  - 選了主題後，可以只看**偏多、中性或偏空**。
  - 已過時的重點預設隱藏，勾「顯示已過時」才會出現。
- 重點很多時，先顯示最新的 150 條，按「再顯示」看更多。

**我的策略**
- 時間軸上方切到「我的策略」分頁，可以新增、編輯你自己的觀察條件和加減碼構想。
- 策略不會變成交易紀錄，也不會出現在 K 線和星系圖上。

**其他操作**
- 「+」：手動新增一條重點，可以選類型、填分析師；不確定日期就勾「不確定確切日期」。「進階」裡可以設定狀態、標記已查證、相關主題、分析日期，以及移除依據連結。
- 清單圖示：打開「資料整理」（只列這一檔）。
- 點一條重點可以展開全文；按 K 線圖示會跳到 K 線上的那一天。
- 刪除重點會先放進回收桶，提示上可以按「復原」。

### 公司資料與財報
左下區塊上方有三個分頁：**交易與損益**、**公司**、**財報**（手機在「交易・公司」裡）。按「展開」變成全螢幕，左邊是公司資料，右邊是財報。每個區塊都可以點標題收起或展開，網頁會記住。

**公司**
- 產業、上市或上櫃，以及 Goodinfo、Yahoo 股市、公開資訊觀測站的連結（美股是 Yahoo Finance、SEC 申報）。
- **估值**：
  - 本益比：台股顯示證交所公布的，另外用現價和近四季 EPS 算一個即時的。美股用近四季 EPS 計算。
  - 股價淨值比、殖利率、市值、近四季 EPS。
  - 預估本益比：用重點裡的 EPS 預估計算。
- **基本資料**（台股）：公司全名、董事長、總經理、成立和上市日期、實收資本額、發行股數、網址。
- **股利**：每年的股利長條圖，以及最近幾次的除息日和金額。

**財報**
- **季度財報**：長條是營收（顏色代表年增或年減），折線是毛利率；表格有營收、年增、毛利率、營益率、淨利率、EPS 和資料來源。官方財報是累計數，網站會換算成單季。
- **月營收**（台股）：最近 13 個月的長條圖（全螢幕是 24 個月），表格有月增、年增、累計年增。
- **年度財報**（全螢幕）。
- **財報與重點對照**：「營收財報」類、有財報期間的重點，會拿 EPS、毛利率、營收和官方數字比對。結果也會標在時間軸上：「財報一致」或「與財報不同」，滑過去看得到財報的數字。
- 下方會寫資料來源和更新時間；某個來源這次沒抓到，也會寫出來。

### 新聞
時間軸上方的「新聞」分頁，是這一檔的新聞收件匣。**新聞不會自動變成重點**，你同意後才會。
- **合併**：同一件事有好幾家報導，合併成一張卡，按「N 則相關報導」可以看各家的標題和連結。
- **可能的雜訊**先收起來：純股價漲跌、盤勢或排行、標題沒提到這家公司的。勾「顯示可能的雜訊」就看得到。漲停、跌停、處置股、創新高或新低不算雜訊。
- **篩選**：未處理、已加入、已略過、全部；也可以只看公司公告。
- 每張卡右上角是**建議的主題**（依標題關鍵字判斷），加入時可以改。
- **加入重點**：標題、日期、來源、連結和主題都先填好，確認後按儲存。這幾則新聞會標成「已加入」。
- **略過**：不需要的就略過，之後在「已略過」可以恢復。
- **交給 ChatGPT 整理**：勾選幾則，按「交給 ChatGPT 整理」，複製指令貼到 ChatGPT（開新對話就可以）。把回覆貼回「貼上匯入」：
  - 重點會自動帶入新聞的來源、連結和發布日（不用 ChatGPT 給的連結）。
  - 用到的新聞標成「已加入」；ChatGPT 認為不用記的，可以一起標成「略過」。
  - ChatGPT 從新聞推論出來的看法放 AI research，會連到依據。
- 新聞量會畫在 K 線的成交量區上方，滑到那根 K 棒會顯示「新聞 N 則」。
- 預設讀這個月和上個月的新聞；更早的按「載入 某月 的新聞」。
- 「資料整理 → 新聞」可以看**所有標的**的新聞，量大時一次勾選、略過或交給 ChatGPT。

### 資料整理
用來清理大量資料，例如匯入後刪雜訊、合併重複的子主題。從右上角的清單圖示（所有標的），或時間軸上的清單圖示（只看那一檔）打開。之後掛新聞進來、資料很多也能順順地用：表格只畫看得到的那幾列。

**重點**
- **篩選**：標的、主題、子主題、看法、類型、來源（外部資訊／AI research）、分析師、狀態（目前、待檢視、已過時、待補證據、已查證）、匯入批次、日期區間、關鍵字。選了主題時，可以勾「含相關的 AI 推論」。手機上按「篩選」展開。
- 上方會顯示篩選結果的多空統計。
- 點表頭可以排序；點一列可以編輯那一條。
- **勾選**：
  - 點每列前面的方框；按住 Shift 可以一次勾一段。
  - 表頭的方框或「全選」會選取**目前篩選結果**的全部。換篩選時，看不到的會自動取消選取，避免誤刪。
- **批次動作**：刪除、移動分類、改看法、改類型、改狀態、連結依據；「更多動作」裡還有標記已查證、取消已查證、設定分析師、改到別的標的、移除依據連結。
  - 每個動作做完，提示上都可以按「復原」。
  - 「自述」類型（分析師自稱買進或持有）一律維持中性。
- **連結依據**：勾選 AI 推論（同一檔），按「連結依據」，再從清單裡勾選支持它的資料。
- **找疑似重複**：
  - 找出同一檔、文字相近、日期相差 14 天以內的重點，一組一組列出。標題裡的數字不同（例如不同季度的營收）不會被當成重複。
  - 「每組保留一條，勾選其餘」會留下資訊最完整的那條，再按「刪除」。
  - 不是重複的，按「不是重複」，之後就不會再列出。

**分類**
- 列出每個主題、子主題的條數。範圍可以選一檔，或全部標的一起處理。
- 名稱很像的子主題會標「疑似同義」。
- 勾選同一個主題下的幾個子主題，按「合併勾選的子主題」，選要合併成哪個名稱。
- 「改名／移動」可以改子主題名稱，或移到別的主題；改成已有的名稱就會合併。
- 規範裡的固定子主題標「固定」，不能改名，但可以把別的子主題併進來。
- 不在規範裡的主題可以「併入其他主題」。

**匯入紀錄**
- 每次匯入的時間、檔名、條數和標的。
- 「查看這批」只列那次匯入的重點；「復原這次匯入」把那批整個移到回收桶（之後再匯入，不會被當成「刪除過」）。

**回收桶**
- 刪除的重點保留 30 天，可以勾選還原或永久刪除。
- 還原的重點，之後再匯入時就不會被標成「之前刪除過」。

### 調整版面大小（電腦）
- 四個區塊之間的空隙就是分隔線，滑鼠移上去會出現一條短線：
  - 左右欄中間那條：調整左右寬度。
  - 每一欄中間那條：調整上下高度。
- 拖拉就能調整，設定會記在這台裝置上；雙擊分隔線就會還原。
- 內容會跟著尺寸重新排版：K 線和星系圖會重畫，表格太窄時會自動收起次要欄位（例如市值、手續費），指標格也會自動換行。

### Memory 銀河系
- 在報價區右上角按「Memory」打開；電腦版的時間軸右上角也有。
- 畫面的意思：
  - 中心發光的是**星系核心**，也就是這檔標的。
  - 每個主題是一條**旋臂**上的亮星，往外依序是子主題、重點。主題用不同顏色區分，越大代表累積的重點越多。
  - 最外圈的小星星是一條條重點，顏色代表看法（偏多、偏空照當地漲跌色，中性是藍色）。
- 打開時，星系會旋轉著展開。之後預設**不會自己轉**；想讓它慢慢轉，按右下角的「⟳ 旋轉」，再按一次就停。「重設視角」會回到一開始的角度、位置和大小。
- **電腦**：
  - 左鍵拖曳：旋轉，不限角度，可以轉到正上方、正下方，甚至翻到背面。
  - 右鍵拖曳或 Shift＋拖曳：平移畫面，星系不會被固定在中央。
  - 滾輪：以游標位置為中心縮放，想看哪一區就把游標移到那裡再捲。
  - 雙擊：放大那一區；雙擊星星會放大並把它移到中央。
- **手機**：單指旋轉；雙指同時縮放和平移。
- 右下角的 **－／＋** 也可以縮放。
- 點一顆星（或在右邊點一個主題、一張卡），畫面會把它平滑移到正中央。從核心到那顆星的連線會發亮，並有光點沿著連線流動。放大後邊緣的星星，也是點一下就移到中間。
- 右邊的面板（手機在下方）：
  - 最上方是**多空指標**：整檔、主題、子主題三層都有，外部資訊和 AI research 分開算，多空比 = 偏多條數 ÷ 偏空條數（中性不算）。主題列表右邊也有每個主題的小比例條和多空比。
  - 點主題，列出底下所有子主題，以及每條重點的完整內容，不用一條條點開。分析師看法還會依分析師分開列。
  - 在主題（和它的子主題）裡，可以只看**偏多、中性或偏空**；不符合的星星會變暗，也點不到。回到全部時會自動清掉。
  - AI 推論的卡片會列出依據，點一下就移到那顆星。
  - 已過時的重點不會出現在星系裡。重點很多時，每個子主題只畫最新的一部分星星，其餘在面板裡看得到。
  - 想先看標題，按「全部收起」；收起時點某一張卡，只展開那一張。
  - 每張卡都可以按 K 線圖示跳到 K 線上的那一天，或按鉛筆圖示編輯。
- 面板和星空中間也有分隔線，可以拖拉調整寬度。

### 備份
- 設定裡可以「匯出備份」，存成一個 JSON 檔。
- 私人 repo 的 commit 歷史本身也是備份，每次修改都看得到。

## 常見問題

**價格一直沒變？**
先確認是不是收盤或假日。再看看右上角是不是顯示紅字錯誤。

**某檔台股抓不到？**
興櫃股票不在證交所即時資料裡，會改用 Yahoo（可能延遲約 20 分鐘），如果 Yahoo 也沒有就抓不到。

**台股價格旁邊顯示「可能延遲」？**
證交所那次沒有回應，程式自動改用 Yahoo 的資料。下一次更新通常就會恢復。

**證交所或 Yahoo 改版，突然全部抓不到？**
這兩個都是非官方的資料來源，偶爾會發生這種事。把錯誤訊息截圖給我，改 Code.gs 就好，網頁本身不用動。

**同步失敗？**
滑鼠移到雲朵圖示上可以看到原因：
- 「token 無效或已過期」：重新產生一個 token。
- 「找不到資料 repo」：檢查 repo 名稱，以及 token 是否有勾選這個 repo。

**兩台裝置同時改了資料？**
網頁會問你要保留雲端的版本，還是這台裝置的版本。

**K 線顯示「載入失敗」？**
先確認報價來源設定好了，再按右上角重新整理。歷史資料來自 Yahoo，上市、上櫃會自動判斷。剛上市的股票可能資料比較少。

**ChatGPT 的回覆貼上後顯示「看不懂這段內容」？**
通常是 ChatGPT 沒有照格式回答。跟它說「請照剛剛的格式，只輸出 JSON 程式碼區塊」，再貼一次就好。

**新聞分頁顯示「Apps Script 需要更新」？**
你的 Apps Script 還是舊版。照「步驟五：新聞收集」更新 Code.gs、執行 setupNews，並部署新版本。

**公司或財報分頁一直顯示「讀取中」？**
第一次讀取某一檔時，Apps Script 要先去收集，可能要半分鐘。稍等一下再按「更新」。如果顯示「Apps Script 需要更新」，請照「步驟五」重新貼上 Code.gs 並部署新版本。

**財報少了幾季，或月營收只有一兩個月？**
官方只提供最新一期，網站每期都會存下來，之後就會越來越完整。更早的季度由 Yahoo 補，偶爾 Yahoo 也沒有。

**新聞一直沒有出現？**
到「設定 → 新聞收集」看看：有沒有顯示「每 1 小時自動收集」、追蹤幾檔、各來源是否有錯誤。可以先按「立即收集一次」。

**畫面上方出現「儲存空間不足」？**
資料主要存在瀏覽器的資料庫，一般用不完。如果還是出現，代表這台裝置的瀏覽器空間滿了：有設定 GitHub 同步的話資料還在雲端；沒有的話，請先按「匯出備份」。

**換手機或清掉瀏覽器資料？**
重新填 token，資料就會從私人 repo 拿回來。
