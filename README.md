# 持股追蹤（第一階段）

台股＋美股的持股追蹤網頁。電腦和手機都能用，資料會自動同步。

**這一階段有：**
- 持有／觀察列表
- 即時報價（台股約 5 秒更新，盤中自動刷新）
- 交易與股利紀錄，手續費和證交稅自動帶入
- 平均成本、未實現損益、已實現損益、股利、預期損益
- 深色／淺色切換

**第二、三階段加入：** K 線、ChatGPT 重點時間軸、Memory 腦圖。

---

## 檔案

| 檔案 | 放哪裡 |
|---|---|
| `index.html` | 網頁本體，放到 GitHub Pages |
| `apps-script/Code.gs` | 報價中繼，貼到 Google Apps Script |
| `README.md` | 這份說明 |

**先試看看：** 直接用瀏覽器打開 `index.html`，按「看示範資料」就能看到畫面（示範報價是假的）。

---

## 整體怎麼運作

```
你的電腦／手機（瀏覽器）
   ├─ 網頁本體 ← GitHub Pages（公開，只有程式，沒有你的資料）
   ├─ 即時報價 ← Google Apps Script ← 證交所／Yahoo Finance
   └─ 持股資料 ⇄ 你的 GitHub 私人 repo（data.json）
```

- 網頁程式碼是公開的，但裡面沒有任何個人資料。
- 你的持股和交易只存在兩個地方：你的瀏覽器，和你自己的**私人** repo。
- 每次儲存都會在私人 repo 留下一個版本，萬一改錯可以從歷史紀錄找回來。

## 步驟一：部署報價中繼（Google 帳號，約 5 分鐘）

1. 打開 <https://script.google.com>，按「新專案」。
2. 刪掉編輯器裡預設的內容，把 `apps-script/Code.gs` 整份貼上，按 Ctrl+S（Mac 是 ⌘+S）存檔。左上角的專案名稱可以改成「持股追蹤報價」。
3. **授權（只需要一次）：**
   1. 上方工具列的函式選單選 `testSetup`，按「執行」。
   2. 跳出「需要授權」時按「審查權限」，選你的 Google 帳號。
   3. 看到「Google 尚未驗證這個應用程式」是正常的，因為這是你自己寫的程式。按「進階」，再按「前往…（不安全）」，最後按「允許」。
   4. 下方「執行紀錄」出現台積電、美股和匯率的資料，就代表成功了。
4. **部署：**
   1. 右上角按「部署」，選「新增部署作業」。
   2. 按左邊的齒輪，類型選「網頁應用程式」。
   3. 「執行身分」選**我**，「誰可以存取」選**所有人**。
   4. 按「部署」，把「網頁應用程式網址」複製下來（結尾是 `/exec`）。
5. **確認：** 在瀏覽器打開「剛剛的網址 + `?tw=2330&us=AAPL&fx=1`」，看到一串 JSON 資料就成功了。

> 「所有人」的意思是拿到這個網址的人可以用它查股價。這個中繼只會轉傳公開的股價，不會碰到你的持股資料。如果還是想上鎖，可以在 `Code.gs` 最上面的 `ACCESS_KEY` 填一段密語，網頁設定的「存取密語」也填一樣的。

> **之後如果改了 Code.gs：** 到「部署 → 管理部署作業」，按鉛筆圖示，版本選「新版本」，再按「部署」。網址不會變。

## 步驟二：建立兩個 GitHub repo

### A. 放網頁的公開 repo

1. 登入 GitHub，右上角按「+」，選「New repository」。
2. Repository name 填 `stock-tracker`，選 **Public**，按「Create repository」。
3. 在新 repo 的頁面按「uploading an existing file」，把 `index.html` 拖進去，按「Commit changes」。
   - 只放 `index.html` 就好。
   - 如果你在 Code.gs 設了 ACCESS_KEY，**不要**把 Code.gs 傳上來。
4. 到 repo 的 **Settings → Pages**：
   - Source 選「Deploy from a branch」。
   - Branch 選「main」和「/ (root)」，按「Save」。
5. 等 1～2 分鐘，重新整理頁面，上方會出現網址：`https://你的帳號.github.io/stock-tracker/`。

### B. 放資料的私人 repo

1. 再建一個新 repo，名稱填 `stock-tracker-data`，這次選 **Private**，按「Create repository」。
2. 裡面空的就好，網頁第一次同步時會自動建立 `data.json`。

## 步驟三：建立 GitHub token（同步用）

這個 token 只能讀寫 `stock-tracker-data` 這一個 repo，碰不到你其他的東西。

1. GitHub 右上角頭像 → **Settings** → 左側最下面 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**。
2. 設定：
   - **Token name**：`持股追蹤`
   - **Expiration**：選長一點。到期後重新產生一個，填回網頁就好。
   - **Repository access**：選「Only select repositories」，然後只勾 `stock-tracker-data`。
   - **Permissions**：找到 **Contents**，設成 **Read and write**。Metadata 會自動變成唯讀，這是正常的。
3. 按「Generate token」，把 `github_pat_…` 開頭的那串複製下來。**這串只會顯示一次**，先貼在安全的地方。

## 步驟四：開始使用

### 電腦

1. 打開 `https://你的帳號.github.io/stock-tracker/`。
2. 右上角的設定圖示（滑桿形狀）：
   - **報價來源**：貼上步驟一的 `/exec` 網址。
   - **GitHub token**：貼上步驟三的 token。
   - **資料 repo**：如果名稱是 `stock-tracker-data`，留空即可。
   - **台股手續費折扣**：照你的券商填，例如 2.8 折填 `0.28`，6 折填 `0.6`。
3. 按「儲存」。右上角的雲朵圖示不是紅色或橘色，就代表同步好了。
4. 按「新增標的」開始建立持股：
   - 選「已持有」，接著會直接跳出買進交易的視窗。
   - 選「觀察中」，就只追蹤價格和目標價。

### 手機

1. 用手機打開同一個網址。
2. 到設定，**只要貼 GitHub token** 就好。報價來源和手續費設定會跟著資料一起同步過來。
3. 加到主畫面，用起來就像一個 App：
   - **iPhone（Safari）**：按分享按鈕，選「加入主畫面」。
   - **Android（Chrome）**：按右上角 ⋮，選「加到主畫面」。

## 使用說明

### 持有和觀察
- 持股大於 0 的標的會出現在「持有」。
- 沒有交易紀錄，或已經全部賣光的，會出現在「觀察」。賣光的標的仍然保留已實現損益。

### 交易
- 手續費和證交稅會依設定自動算：
  - 手續費無條件捨去，並套用最低手續費（整股 20 元、零股 1 元，可以改）。
  - 證交稅：股票 0.3%；代號 00 開頭的 ETF 用 0.1%。
- 自動算的金額可以直接改成對帳單上的實際金額，改過的欄位就不會再被自動覆蓋。

### 股利
- **現金股利**：填股利總額和扣除額。台股的扣除額包括二代健保補充保費、匯費；美股是預扣稅，一般是 30%。
- **股票股利（配股）**：填配發股數。持股會增加，總成本不變，所以平均成本會下降。

### 損益怎麼算
| 項目 | 算法 |
|---|---|
| 平均成本 | 移動平均，含買進手續費 |
| 已實現損益 | 賣出所得（扣手續費和稅）− 賣出股數 × 當時平均成本 |
| 未實現損益 | 市值 − 預估賣出手續費 − 預估證交稅 − 持有成本 |
| 預期損益 | 用目標價算的未實現損益（一樣扣除預估的費用和稅） |
| 總報酬 | 已實現 + 未實現 + 股利實收 |

頂部的總覽用台幣合計，美股用即時匯率換算。

### 顏色
- 台股：紅漲綠跌。
- 美股：綠漲紅跌。
- 頂部的台幣合計照台股習慣。
- 每個數字都有 ▲▼ 和正負號，不用只看顏色。

### 更新頻率
- 台股 9:00～13:30、美股 9:30～16:00（紐約時間）的平日，會照設定的秒數自動更新，預設 10 秒。
- 收盤後就停止自動更新，打開網頁或切回網頁時會抓一次最新價格。
- 國定假日沒有特別判斷，會照常嘗試更新，但價格不會變。

### 備份
- 設定裡可以「匯出備份」，存成一個 JSON 檔。
- 私人 repo 的 commit 歷史本身也是備份，每次修改都看得到。

## 常見問題

**價格一直沒變？**
先確認是不是收盤或假日。再看看右上角是不是顯示紅字錯誤。

**某檔台股抓不到？**
興櫃股票不在證交所即時資料裡，會改用 Yahoo（可能延遲約 20 分鐘），如果 Yahoo 也沒有就抓不到。

**台股價格旁邊顯示「可能延遲」？**
證交所那次沒有回應，程式自動改用 Yahoo 的資料。下一次更新通常就會恢復。

**證交所或 Yahoo 改版，突然全部抓不到？**
這兩個都是非官方的資料來源，偶爾會發生這種事。把錯誤訊息截圖給我，改 Code.gs 就好，網頁本身不用動。

**同步失敗？**
滑鼠移到雲朵圖示上可以看到原因：
- 「token 無效或已過期」：重新產生一個 token。
- 「找不到資料 repo」：檢查 repo 名稱，以及 token 是否有勾選這個 repo。

**兩台裝置同時改了資料？**
網頁會問你要保留雲端的版本，還是這台裝置的版本。

**換手機或清掉瀏覽器資料？**
重新填 token，資料就會從私人 repo 拿回來。
